# 픽셀 마법사 연구소

> 작은 픽셀에 마법을 걸어봐!

초등학생(1~6학년, 주 대상 2~4학년)을 위한 **창작형 코딩 교육 웹앱**입니다.
명령 블록을 조립해 마법 펜을 움직이고, 픽셀 그림을 그리고, 그 그림을 애니메이션으로 움직입니다.

- 회원가입·로그인 없음, 서버·데이터베이스·API 키 없음
- 작품과 미션 기록은 브라우저 저장소(localStorage)에 보관 → 새로고침해도 유지
- 정적 웹 호스팅(학교 서버, GitHub Pages, Netlify 등)에 그대로 올려서 사용

---

## 1. 바로 사용하기 (빌드된 파일)

### 가장 쉬운 방법: HTML 파일 하나

`pixel-magic-lab.html` 파일 하나에 앱 전체(코드, 디자인, 글꼴)가 들어 있습니다(약 3.4MB).
더블클릭해서 브라우저로 열거나(서버 없이 `file://`로 열어 미션을 성공하는 과정까지 브라우저 자동 테스트로 확인합니다), USB·메신저·클래스룸으로 학생들에게 나눠 주면 됩니다. 인터넷 연결이 없어도 됩니다.
다시 만들려면 `npm run build:html`을 실행하세요.

### 여러 파일 버전

`dist/` 폴더도 완성된 웹앱입니다(웹 호스팅용, 처음 열 때 더 가벼움).

| 방법          | 설명                                                                                                                                                                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 웹 호스팅     | `dist/` 폴더 안의 파일 전체를 웹 서버에 올리면 끝. 하위 경로(`/class/pixel/`)에 올려도 동작합니다.                                                                                                                                                                                   |
| 내 컴퓨터에서 | 프로젝트 폴더에서 `npm install` 후 `npm run preview` → 브라우저에서 `http://localhost:4173`                                                                                                                                                                                          |
| 파일로 열기   | `dist/index.html`을 더블클릭해도 열리도록 모듈이 아닌 일반 스크립트로 빌드했습니다. (자동 확인은 웹 서버 방식으로 했고, 파일 직접 열기는 브라우저 보안 설정에 따라 글꼴이 기본 글꼴로 보이거나 저장 기록이 따로 보관될 수 있습니다.) 수업에서는 웹 서버 주소로 여는 것을 권장합니다. |

권장 브라우저: 최신 Chrome / Edge / Whale / Safari. 화면 기준: 1366×768(100% 배율)에서 스크롤 없이 모든 주요 기능이 보이며, 1280×720과 태블릿(세로·가로)도 지원합니다.

## 2. 개발 환경에서 실행하기

필요: Node.js 22 이상

```bash
npm install          # 처음 한 번
npm run dev          # 개발 서버 (http://localhost:5173)
npm run check        # 한 번에: 타입 검사 + 코드 검사 + 형식 검사 + 단위·화면 테스트
npm run test:e2e     # 빌드 후 브라우저 자동 테스트 (Playwright, 내 컴퓨터에서는 설치된 Edge 사용)
npm run build        # 배포용 빌드 → dist/
npm run build:html   # HTML 파일 하나로 빌드 → pixel-magic-lab.html
npm run format       # 코드 모양 맞추기 (Prettier)
```

| 명령                   | 하는 일                                                 |
| ---------------------- | ------------------------------------------------------- |
| `npm run typecheck`    | TypeScript 타입 검사                                    |
| `npm run lint`         | 코드 검사 (oxlint: 정확성, React 규칙, 접근성 규칙)     |
| `npm run format:check` | 코드 모양이 Prettier 규칙과 맞는지                      |
| `npm test`             | 단위 테스트(node) + 화면 테스트(jsdom, Testing Library) |

GitHub에 올리면 Actions(`.github/workflows/ci.yml`)가 위 검사, 두 가지 빌드, 브라우저 테스트(Chromium)를 자동으로 돌리고, main에서 모두 통과하면 GitHub Pages에 배포합니다.

- 빠른 일반 빌드: https://yys10413400.github.io/pixel-magic-lab/
- 한 파일 HTML: https://yys10413400.github.io/pixel-magic-lab/pixel-magic-lab.html

코드 검사에서 끈 규칙과 이유: `prefer-tag-over-role`(버튼 묶음의 radiogroup/radio와 직접 만든 대화상자는 올바른 ARIA 패턴), `no-array-sort`(복사본만 정렬), `consistent-function-scoping`(스타일 규칙), 테스트 안의 `no-await-in-loop`(클릭은 순서대로 해야 함). typescript-eslint는 아직 TypeScript 7을 지원하지 않아 oxlint를 씁니다.

## 3. 세 가지 모드

### A. 마법 따라 그리기 (미션 12개)

목표 그림과 똑같이 그리는 코딩 미션. 한 미션에 새 개념을 하나씩 더합니다.

| #   | 미션              | 난이도 | 핵심 학습                          |
| --- | ----------------- | ------ | ---------------------------------- |
| 1   | 첫 번째 마법 점   | 쉬움   | 색칠 명령                          |
| 2   | 반짝이는 가로줄   | 쉬움   | 이동과 순서                        |
| 3   | 알록달록 계단     | 쉬움   | 방향 명령 (+ 색 바꾸기)            |
| 4   | 네모난 마법 창문  | 쉬움   | 이동과 패턴                        |
| 5   | 하트 만들기       | 쉬움   | 좌표와 색칠                        |
| 6   | 반복되는 무지개   | 보통   | 반복문                             |
| 7   | 마법사의 꽃       | 보통   | 반복과 패턴                        |
| 8   | 별빛 장식         | 보통   | 효율적인 명령                      |
| 9   | 귀여운 버섯       | 보통   | 색 변경과 반복                     |
| 10  | 마법사의 시험     | 도전   | 종합 미션                          |
| 11  | 고장 난 마법 주문 | 도전   | 디버깅 (버그가 있는 코드를 고치기) |
| 12  | 체크무늬 마법진   | 도전   | 중첩 반복                          |

- 성공 판정: 완성 그림의 모든 칸 색이 목표와 같으면 성공. **코드 순서가 정답 예시와 달라도 결과가 같으면 성공**입니다.
- 별: 성공 1개 · 블록 수가 정답 예시의 1.5배 이하 2개 · 정답 예시 이하 3개(효율 보너스)
- 실패하면 다른 칸을 **모양으로** 표시합니다: 칠해야 하는데 빈 칸 = 점선 동그라미, 잘못 칠한 칸 = X
- 힌트 3단계 → 마지막에 정답 예시 코드 보기/불러오기
- 새 개념이 나오는 미션은 처음 열 때 짧은 개념 소개 카드가 나옵니다.
- 미션 성공 시 다음 미션 잠금 해제, 완료 도장, 별, 마법사 칭호

### B. 자유 픽셀 공방

- 8×8 / 10×10 / 16×16 도화지, 12색 팔레트
- 기본은 **코드로 그리기**. 보조 기능으로 **손으로 칠하기 / 손 지우개**(밑그림 층) — 코드는 밑그림 위에 그려집니다.
- 되돌리기 / 다시하기 (Ctrl+Z / Ctrl+Y)
- 작품 이름, 저장(이름·픽셀·명령 블록·크기·수정 날짜), 작품 보관함(열기·PNG·삭제 확인), PNG 내려받기
- 작업 중인 작품은 자동 임시 저장되어 새로고침해도 이어서 만들 수 있습니다.

### C. 움직이는 픽셀 극장

- 장면(프레임) 추가 / 복사해서 추가 / 삭제 / 순서 옮기기
- **앞 장면 비춰보기**(어니언 스킨)
- 장면마다 명령 블록과 손 그림을 따로 보관
- 재생 / 멈추기, 속도(초당 2·4·8장), 반복 재생
- 저장 / 보관함, **움직이는 GIF 내려받기**, 장면 모음 PNG(스프라이트 시트) 내려받기
- 예시 템플릿 6개: 눈 깜빡이는 고양이, 통통 뛰는 토끼, 반짝이는 별, 피어나는 꽃, 걷는 공룡, 코드로 굴리는 공(프레임마다 반복 횟수만 바꿔 움직임)

## 4. 코딩 블록과 실행 규칙

| 블록                                      | 하는 일                                      |
| ----------------------------------------- | -------------------------------------------- |
| 위로 / 아래로 / 왼쪽으로 / 오른쪽으로 1칸 | 펜 위치만 옮김 (칠하지 않음)                 |
| 색칠하기                                  | 펜이 있는 칸을 현재 색으로 칠함              |
| 지우기                                    | 펜이 있는 칸을 빈칸으로                      |
| 색 바꾸기                                 | 펜 색 변경 (12색)                            |
| N번 반복하기                              | 안쪽 블록을 N번 실행. 반복 안에 반복 3겹까지 |

- 좌표는 (가로, 세로), 왼쪽 위가 (0,0). 펜은 보라색으로 출발하며 처음 칸은 칠하지 않습니다. 출발 칸은 미션 모드에서 (0,0), 자유 공방·픽셀 극장에서는 도화지 가운데입니다(짝수 크기는 가운데 4칸 중 오른쪽 아래 칸: 8×8 → (4,4), 10×10 → (5,5), 16×16 → (8,8)).
- 실행할 때마다 도화지를 초기화하므로 결과가 섞이지 않습니다.
- 도화지 밖으로 나가면 실행이 멈추고, 문제의 블록에 빨간 표시와 이유("앗! 마법 펜이 도화지 밖으로 나가려고 해요!")가 나타나며 도화지에는 나가려던 방향이 표시됩니다.
- 안전 장치: 반복 횟수 최대 30, 전체 실행 단계 최대 5000, 중첩 3겹.

**블록 편집**: 블록 클릭 → ✦ 자리에 추가 / 끌어서 놓기(마우스·터치) / 블록을 팔레트로 끌어 놓으면 삭제 / 블록을 눌러 선택하면 ▲▼(반복 안·밖으로도 이동), 복사, 지우기 버튼 / 반복 횟수 −·+(1~30, 숫자를 직접 쓸 수도 있어요) / 색 블록의 색 바꾸기 / 키보드: Tab으로 블록 이동, Enter로 고르기, Delete로 지우기, Alt+↑/↓로 옮기기, Esc로 고르기 취소.

**실행 도구**: 실행하기 · 일시정지 · 계속하기 · 한 단계 · 처음부터 · 초기화 · 속도(느리게/보통/빠르게/바로). 실행 중인 블록 강조, 반복 블록에 "2/6" 같은 현재 반복 회차 표시, 펜 위치·색·단계 상태 표시.

## 5. 선생님 도구 (상단 칠판 아이콘)

- 모든 미션 잠금 해제 (수업 진도에 맞춰 바로 이동)
- 미션 진행 현황표 (별, 최고 블록 수 / 정답 예시 블록 수)
- 미션 기록 초기화 (확인 후)
- 전체 화면 버튼, 효과음 끄기 버튼은 상단에 항상 있습니다.

## 디자인 원칙: "말랑한 마법 사탕"

- **귀엽지만 깔끔하게.** 바탕은 무늬 없는 연한 라벤더(`#f3f1fb`) 한 가지 색이고, 테두리 선은 거의 쓰지 않아요. 글씨는 부드러운 남색(`#2f2b4f`)이에요.
- **대표 질감은 사탕 그림자.** 버튼과 블록 아래에 같은 색의 진한 띠(3~5px)를 깔아서, 누르면 말랑하게 납작해져요. 흐린 회색 그림자는 카드에만 아주 옅게 써요.
- **모서리는 역할마다 달라요.** 팝업 28px, 카드 24px, 블록과 버튼 14px, 칩과 탭은 동그랗게 둥글려요. 픽셀 모양은 도화지 칸과 마법사 캐릭터에만 남겼어요.
- **색은 뜻을 가져요.** 이동은 하늘색, 색칠은 분홍색, 색 바꾸기는 노란색, 반복은 민트색, 지우기는 회색이에요. 블록은 연한 채움에 진한 색 동그라미 아이콘을 달았어요. 보라색(`#7457f0`)은 화면마다 하나뿐인 주 버튼(실행하기)과 고른 블록 고리에, 노란색은 실행 중인 블록, 별, 극장의 재생에 써요.
- **픽셀 마법사가 안내해요.** 직접 그린 16×16 캐릭터가 미션 이야기, 성공, 실수를 말풍선으로 알려 주고, 표정(기본, 기쁨, 앗!)이 바뀔 때만 한 번 움직여요.
- **읽기 쉽게.** 글씨는 최소 14px, 누르는 곳은 최소 44px이고, 글씨 대비는 모두 4.5:1 이상이에요. 도화지는 바깥 경계선까지 그려서 가장자리 칸도 셀 수 있어요. 움직임 줄이기 설정을 따라요.
- 디자인 값은 `src/styles/00-tokens.css`에 모여 있어요. 화면 사진은 개발 서버를 켠 뒤 `node scripts/screens.mjs http://localhost:5173 1366x768`로 찍어요(`screens/` 폴더).

## 6. 프로젝트 구조


### 저장 데이터 버전

공방 작품, 애니메이션, 작업 중 임시 저장에는 `schema: 2`가 붙습니다. 표시가 없는 예전 데이터에는 두 종류가 섞여 있어요. 처음 버전에서는 공방·극장 펜이 (0,0)에서 출발했고, 그다음 버전부터는 가운데에서 출발했기 때문이에요. 그래서 읽을 때 이렇게 판단해서 바꾸고 다시 저장합니다.

- 공방 작품: 저장된 완성 그림과 비교합니다. (0,0) 출발일 때만 그 그림이 나오면 코드 맨 앞에 [가운데 → (0,0)] 이동 반복 블록 2개를 붙여 그림이 그대로 보이게 합니다.
- 극장 장면·임시 저장: 완성 그림이 없어서, 가운데 출발로는 도화지 밖으로 나가는데 (0,0) 출발로는 문제없을 때만 바꿉니다. 두 방식 모두 오류 없이 실행되는 코드는 그대로 둡니다.

그래픽은 모두 CSS와 SVG로 직접 그렸습니다(외부 이미지·이모지 없음). 글꼴: Jua, Gowun Dodum (SIL Open Font License, `@fontsource` 패키지로 빌드에 포함되어 인터넷 없이도 표시).

## 접근성과 성능

**키보드로 쓰기**

- Tab: 다음 버튼으로 이동해요. "하나 고르기" 묶음(도화지 크기, 그리기 방법, 속도, 손 그림 물감)은 Tab 한 번에 들어가고 ← → 로 골라요.
- 블록: Tab으로 블록에 가서 Enter로 고르고, Alt+↑/↓로 옮기고, Delete로 지우고, Esc로 고르기를 취소해요.
- 팝업: 열리면 가장 알맞은 버튼(예: [알겠어요!], [다음 미션])에 초점이 가요. Tab은 팝업 안에서만 돌고, Esc로 닫으면 초점이 원래 자리로 돌아와요. 겹친 팝업은 맨 위 것만 닫혀요.
- 손으로 칠하기는 마우스·터치 전용이에요. 같은 그림은 코드 블록으로 모두 그릴 수 있어요.

**보기 쉽게**

- 글씨 대비 4.5:1 이상, 글씨 최소 14px, 누르는 곳 최소 44px
- 색만으로 구분하지 않아요: 틀린 칸은 X와 점선 동그라미 모양으로, 오류 블록은 "!" 표시와 설명 글로, 실행 중 블록은 화살표로, 블록 종류는 아이콘과 이름으로, 색 바꾸기 블록과 상태 표시줄은 색 이름 글자로도 보여 줘요.
- 한국어 문장은 낱말 중간에서 줄이 바뀌지 않아요.
- 휴대폰 너비(390px)에서도 가로 스크롤이 없고, 모드 탭은 짧은 이름(미션, 공방, 극장)으로 바뀌어요.

**불러오는 양과 속도** (`node scripts/perf.mjs`, 1.6Mbps · 지연 150ms · CPU 4배 느리게)

- JS 하나(압축 전 521KB, 압축 시 약 171KB)와, 화면에 쓰인 글자에 해당하는 한글 글꼴 조각만 내려받아요. 옛 woff 대체 글꼴을 빼서 배포 폴더가 6.0MB에서 3.1MB로 줄었어요.
- 첫 화면은 약 2초 만에 쓸 수 있고, 한글 글꼴은 그 뒤에 도착하면 바뀌어요(그동안 기본 글꼴로 보여요).
